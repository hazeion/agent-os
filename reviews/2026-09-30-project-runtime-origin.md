# Public artifact origin qualification

Build a new disposable qualification candidate solely from the pinned official
Hermes Git archive, checksum-verified Astral standalone Python archive and
public dependency wheels. Installed RECORDs are self-reported integrity data,
not a public origin anchor. Do not copy local generated wrappers, editable
metadata, direct URLs, pycache or the installed Python sysconfig modification.

The reviewed public lock records 111 wheel digests: 106 match the exact official
uv.lock; five explicitly named supplemental PyPI versions match the existing
host installation. The builder verifies that relation against the extracted
SHA-bound upstream lock and requires the complete separately coded five-name
version/SHA pin set; bounded wheel METADATA must match each exact coordinate.
Verify each artifact's actual size and SHA-256 before parsing
immutable in-memory bytes. Bound archive members, expanded sizes, path names and
the aggregate new stage. Refuse duplicate/unsafe/special members and overlapping
wheel destinations. Materialize regular files through no-follow directory FDs
before creating validated in-tree archive links. Generate only fixed virtual
runtime configuration, interpreter aliases, a non-executable source .pth and
the official CLI entry-point wrapper.

Before stdlib decoding, raw tar header preflight bounds PAX/GNU metadata,
extension depth, all declared data and trailing padding; unknown/sparse PAX
keys fail closed. ZIP preflight counts actual bounded central records rather
than trusting the end-record count. Pure bounded link-graph resolution rejects
indirect parent escapes and cycles. The new stage and source-lock read stay
descriptor-pinned; renamed/replaced stage or parent names invalidate success.
The fixed CLI wrapper propagates the upstream main return via SystemExit.

The Linux-only offline utility never downloads, installs, reads owner Hermes
configuration/credentials, executes archive contents, or changes a live service.
It creates a new missing-only private stage. A failed build preserves an
incomplete disposable candidate and reports failure; it never reports it ready.
The new image must still use the bounded system-library projection and pass the
actual isolated unchanged-stock/PIL/prepared-image/durable-broker operation.

Test malformed paths/links/duplicate archives, ZIP special files and relocation,
artifact mismatch, budgets, symlink ancestors and existing-stage refusal. Verify
the public lock in wheel/sdist, exercise the complete new candidate on Linux,
and obtain two independent reviews before publishing a full PR.

Public anchors: [official Hermes commit](https://github.com/NousResearch/hermes-agent/tree/f97608f178d1ffeca59860195ab7da295f7c8e5f)
and [Astral release 20260718](https://github.com/astral-sh/python-build-standalone/releases/tag/20260718).
This evidence cannot establish package safety, complete dlopen behavior,
helper/provider/model readiness, exact Run admission or garage acceptance.

Public comparisons found 8,843 selected wheel members equal to installed bytes
and all 15,075 public Git source members equal to the exact local Git archive.
Of 1,374 selected public Python members, one installed sysconfig file differs;
the fresh candidate uses the original public bytes and does not copy that local
modification. It contains 25,409 staged members (584,473,709 bytes), plus 14
selected system-library members (7,768,040 bytes), with fixed virtual runtime
paths and no owner metadata/launcher copies.

Review A found missing executable upstream/supplement provenance checks and
unaccounted ignored tar payload sizes. Both were corrected with rejection
tests; its initial re-review is clear. Review B additionally found early
PAX/GNU/ZIP allocation guards, stage-name replacement and wrapper return-code
gaps; these received corrections and focused refusal tests. Both independent
final re-reviews are clear on the complete corrected code.

The final complete actual Linux group passes all 127 tests with no skips,
including unchanged official Hermes, PIL, accepted native PNG and the durable
fake broker from the fresh five-root sealed image within the existing
20-second policy. Windows runs 13 portable methods and skips four Linux-only
cases. Final exact wheel/sdist public inventory and RECORD verification pass;
an isolated installed module and its default public lock match source bytes.
The initial broader run used a Hermes-only interpreter and four backup checks
lacked argon2; the corrected complete Mentat environment passes those checks.
