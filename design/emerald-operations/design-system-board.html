System states

Design for reality, not only the happy path

Every data surface specifies loading, empty, disconnected, unsupported, stale, and failed behavior.

···Loading

Use stable skeleton rows. Do not collapse the panel.

—Empty

Name what is absent and offer one useful next step.

×Disconnected

State the affected subsystem and when data was last valid.

iUnsupported

Do not render a fake or permanently disabled operation.

!Needs attention

Localize orange to the affected row or message.

!Failed

Use clear failure text and a safe recovery path.

✓Verified

Claim completion only after the underlying operation is verified.

↗Remote hidden

Never surface local CRON data while remote Hermes is selected.
